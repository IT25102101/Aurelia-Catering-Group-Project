# Aurelia-Catering-Group-Project
Aurelia – Web-Based Catering Management System A full-stack web-based catering management system developed as a Year 2 Semester 1 group project. The system streamlines catering operations including customer management, event bookings, orders, quotations, payments, inventory, recipes, delivery management, order reviews, and status tracking.  Technology Stack: React, Vite, Java Spring Boot, JDBC, Microsoft SQL Server, REST APIs, and Git/GitHub.  The project follows a layered architecture with a React frontend, Spring Boot REST backend, DAO/JDBC data-access layer, and SQL Server database. The database includes relational constraints, stored procedures, functions, triggers, and audit history to support the application's business workflows.
